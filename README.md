# The Elite Club

The Elite Club is Chh. Sambhajinagar's most exclusive membership-based liquor club, offering premium experiences across 12+ partner venues.

## 🌟 Features

- **Exclusive Memberships**: Tiered membership levels with unique benefits.
- **Partner Venues**: Access to a curated selection of premium venues.
- **3D Interactive Experience**: Immersive bottle sequence and member portal animations.
- **Admin Dashboard**: Comprehensive management system for memberships and venue scans.
- **QR Code System**: Unique QR codes for seamless check-ins at partner locations.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Framer Motion, Lucide React
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js / Canvas-based animations
- **Routing**: React Router DOM

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ShlokNoval/EliteClub.git
   ```
2. Navigate to the project directory:
   ```bash
   cd EliteClub
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
